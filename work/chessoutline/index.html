ChessOutline

Personal project · Tool · 2026

A chess extension I built for myself, published, and still use every week.

Context

A browser extension that draws chess tactics over the board. I built it because I wanted it, not because it was a portfolio piece, and it is still the version I use.

Built as a tool for myself — 276 installs later I still use it every week

Product

The whole thing started as a personal tool: I wanted tactics laid out visually while I played and studied, so I decided how it should behave and built it.

Publishing it to the Chrome Web Store was the interesting part. Something made for exactly one person had to survive contact with people who did not know what it was for, which is a different problem from making it work.

It sits at 276 installs and around three dozen people using it now. Small numbers, real ones, and it is still maintained because I am one of those users.
