Merge and Run

Vira Games · Runner · 2023

Unity's controller is a capsule. The hero is a cube. So I wrote my own.

Context

You run carrying a number, pick up other numbers along the way and they add together — a hundred plus sixty-two makes a hundred and sixty-two — and the goal is to reach the finish with the largest number you can.

The engine controller is a capsule and the hero is a cube, so I rewrote it

Movement

The hero of this game is a cube carrying a number, and it had to move precisely and react to what it hits.

Unity's character controller is a capsule, which is the wrong shape for a cube, and full physics broke both the feel and the collisions.

So I started from a community kinematic controller and rewrote it around a box collider, with its own jump and impact animations on top. It was also the first project where I drove those animations with tweens rather than an animator.
